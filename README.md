# 樂衍北區工作管理 PAGE · 第二階段互動原型

線上預覽：https://daniel60605.github.io/leyan-north-preview/

## 使用方式
開啟 index.html 或線上預覽，選「報修派工」→ 新增派工 → 只填客戶與問題 → 自動判定與安排 → 檢查地區、類別、工程師與最早可用時段 → 確認派工並加入月曆。
點工單可查看明細、開始處理、待料、建立再訪單、完工或取消。已安排工單可重新排程。
行事曆為空白月份格狀月曆，確認派工後自動顯示事件，可切月份、回到今天、依地區及工程師篩選，點日期看當日明細，點事件回到工單。取消派工即移除事件；重新排程會同步移動。尚無週檢視。

## 已實作
- 地區＋類別固定對應工程師（依使用者要求，已在預覽顯示真實工程師姓名）。
- 報修時間起算72小時內，安排必須在期限前完工；禁止週六；未來報修時間不接受。
- 新增派工預設工時2小時及交通緩衝30分鐘，再訪沿用原工單；同工程師時段衝突及緩衝檢查。
- 無空檔時記錄客戶協調結果，不擅自超期或指派其他人。
- 再訪建立關聯子單，完成子單同步完成等待再訪的父單。
- 關鍵操作時間紀錄、本機localStorage保存、搜尋及狀態／地區篩選。

## 2026-11-14 兩欄自動派工
- 初始只輸入客戶、問題。報修時間自動取現在，工時2小時及緩衝30分鐘採預設；再訪沿用原工單。
- 地區先比對既有示範客戶與已確認工單，沒有紀錄再依客戶名稱的明確地名。相同名稱跨地區或無地名時不猜測，須於確認頁指定。
- 問題關鍵字判定弱電／硬體；同時命中兩類或無法判定時請使用者確認。再訪無明確類別時沿用原工單。不是AI語意模型，尚無正式客戶資料庫。
- 自動對應工程師及預選最早合規空檔，確認頁允許修正地區、類別或時段，確認前不寫入工單或月曆。
- 無空檔時顯示原因，確認後只建立待協調工單，不會超期派工，也不占用月曆。正式派工前再次檢查空檔。
- 已驗證4組工程師規則、已知客戶紀錄、陌生／跨區／混合問題需確認、確認前不寫入、空檔避開衝突、確認後進月曆、無空檔轉待協調、再訪父子結單、輸入跳脫及4種螢幕寬度。

## 2026-11-14 業務案件可編輯
- 案件列表可新增案件；開啟案件詳情後按「編輯案件」。
- 可改客戶／案件名稱、類別、目前階段（原八階段）、總金額、訂金、尾款、訂金收款狀態、尾款收款狀態及備註。
- 收款狀態各自為待收款／已收款；案件階段不與收款狀態強制綁定。結案仍未收齊時顯示提醒。
- 不固定訂金比例；改總額或訂金會重算尾款，尾款仍可手動修改，儲存前驗證訂金＋尾款等於總額。金額採非負整數新台幣元。洽談階段等金額未定案件可留空，不能在總額未定時設定已收款。
- 儀表板待收款為所有已知金額案件的「未收訂金＋未收尾款」，進度卡片、結案統計及提醒依實際案件資料更新。總額未知明確顯示未定，不當成已收齊。
- 儲存鍵 leyan-cases-demo-v1，與派工資料分開；只在本機瀏覽器保留，不跨裝置。取消編輯不寫入，編輯保留原案件ID、日期與聯絡資料。
- 已測新增未定金額案件、修改既有案件、狀態推進、收款切換、金額不一致拒絕保存、取消不改動、重整保留、統計／篩選同步、文字跳脫與四種螢幕寬度。
